应用简介

MD阅读大师 是一款专为 iPhone 设计的原生 Markdown 长文档阅读应用。它帮助用户优雅地阅读、管理和导出以 .md 格式保存的笔记、文档与技术文章，尤其适合几百页的技术手册、读书笔记与课程讲义。内置目录大纲，让长文档也有可把握的结构；应用采用纯原生技术构建，界面简洁、启动迅速、运行稳定。

🌟 纯单机离线应用

MD阅读大师完全在设备本地运行。阅读、编辑、导出、主题切换等所有功能均不依赖网络。应用不会在后台发起任何网络请求，不会收集、上传或共享用户的任何个人数据与文档内容。用户的 Markdown 文件始终保存在自己的设备（或自己选择的「文件」App 位置）中，全程不经过任何服务器。

核心功能

  • 目录大纲：自动从标题生成层级目录，多级缩进清晰呈现文档骨架；点击即跳转，当前章节高亮。再长的文档，也有可把握的结构。
  • 多来源打开：支持从系统「文件」App 原地打开，或从微信、邮件、其他 App 通过「共享 / 打开方式」直接唤起阅读。
  • 最近阅读：自动记录阅读历史，一键续读，支持置顶常用文档。
  • 粘贴即读：复制 Markdown 文本后，可快速粘贴进入阅读界面。
  • 文档内搜索：阅读器顶部搜索条，全文实时高亮匹配，支持上一处 / 下一处跳转。
  • 优雅排版：完整的 Markdown 语法渲染（标题、列表、表格、代码块、引用、数学公式等），暖色纸墨视觉 + 浅色 / 深色 / 护眼等多种阅读主题与字号调节。
  • 导出分享：支持将文档导出为 PDF（高级功能）或复制为纯文本 / HTML，便于归档与分享。

为什么选择单机离线

在隐私日益重要的今天，MD阅读大师坚持「数据不出设备」的设计哲学。对于处理个人笔记、技术文档、学习资料的用户而言，这意味着完全的掌控感与安全感——无需注册账号，无需登录，打开即用。

原创与独立开发

MD阅读大师 由独立开发者使用 SwiftUI 原生独立设计与开发，并非对其他应用的复制、换皮或重新打包，也不包含任何抓取自网络的现成内容。它面向一个明确且细分的场景——「长文档」Markdown 阅读：数百页技术手册、读书笔记、课程讲义在通用阅读器里极易迷失，为此我们专门构建了层级目录大纲、章节跳转与长文排版优化，这是它与通用文本 / 文档工具的本质区别。全部功能均为自研实现，无远程模板、无网页套壳。

关于内购

应用采用一次性买断制（StoreKit 2），用于解锁高级功能（如部分护眼主题与 PDF 导出）。购买为设备内一次性消费，不涉及订阅，也不会向任何第三方泄露支付信息。
