应用简介

MD阅读助手 是一款专为 iPhone 设计的原生 Markdown 阅读应用。它帮助用户优雅地阅读、管理和导出以 .md 格式保存的笔记、文档与技术文章。应用采用纯原生技术构建，界面简洁、启动迅速、运行稳定。

🌟 纯单机离线应用

MD阅读助手完全在设备本地运行。阅读、编辑、导出、主题切换等所有功能均不依赖网络。应用不会在后台发起任何网络请求，不会收集、上传或共享用户的任何个人数据与文档内容。用户的 Markdown 文件始终保存在自己的设备（或自己选择的「文件」App 位置）中，全程不经过任何服务器。

核心功能

  • 多来源打开：支持从系统「文件」App 原地打开，或从微信、邮件、其他 App 通过「共享 / 打开方式」直接唤起阅读。
  • 最近阅读：自动记录阅读历史，一键续读，支持置顶常用文档。
  • 粘贴即读：复制 Markdown 文本后，可快速粘贴进入阅读界面。
  • 优雅排版：完整的 Markdown 语法渲染（标题、列表、表格、代码块、引用、数学公式等），支持浅色 / 深色 / 护眼等多种阅读主题与字号调节。
  • 导出分享：支持将文档导出为 PDF（高级功能）或复制为纯文本 / HTML，便于归档与分享。

为什么选择单机离线

在隐私日益重要的今天，MD阅读助手坚持「数据不出设备」的设计哲学。对于处理个人笔记、技术文档、学习资料的用户而言，这意味着完全的掌控感与安全感——无需注册账号，无需登录，打开即用。

关于内购

应用采用一次性买断制（StoreKit 2），用于解锁高级功能（如部分护眼主题与 PDF 导出）。购买为设备内一次性消费，不涉及订阅，也不会向任何第三方泄露支付信息。
