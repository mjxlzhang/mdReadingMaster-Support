For App Review / English

MD Reading Master is a fully offline, original Markdown reader for iPhone, independently developed in native SwiftUI. It collects no data and makes no background network requests; all rendering (Markdown, KaTeX math, code highlight) runs on-device. For any support request, email mjxlzhang.app@gmail.com.

关于离线说明

MD阅读大师 是一款纯单机离线应用，全部功能在设备本地运行，不依赖网络服务，也不会上传您的任何文档或个人信息。因此您的数据安全完全由您自己的设备掌控。

常见问题

  • 如何打开 Markdown 文件？ 可通过系统「文件」App 直接打开，或从微信、邮件等 App 的「共享 / 打开方式」中选择 MD阅读大师。
  • 文档保存在哪里？ 文档保存在您设备上您自己选择的位置（如「文件」App 的本地或 iCloud 目录），应用不另行上传。
  • 如何使用目录大纲？ 进入阅读后，从顶部或侧边打开目录抽屉，即可看到按标题生成的层级大纲，点击任意章节立即跳转，当前阅读章节会高亮。
  • 如何搜索文档内容？ 在阅读器顶部点击搜索按钮，输入关键词后全文实时高亮匹配，可用上一项 / 下一项在结果间跳转。
  • 应用需要联网吗？ 正常使用无需联网。仅当您主动点击本页或应用内「条款 / 隐私」链接时才会打开浏览器。
  • 如何恢复内购？ 在付费墙中点击「恢复购买」，由 Apple 账户完成验证与恢复。
  • 为什么图片显示占位？ 为坚持单机离线原则，首版暂不自动抓取网络图片，文档内图片以离线占位呈现，后续可按需开启。
